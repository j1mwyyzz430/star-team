# Google Flow · 熔獄龍魂首個 AI 樣片

本資料夾只準備圖生影片素材，尚未在 Google Flow 生成影片。這不是上一版程序動畫的重新命名。

- `t0-inferno.png`：原倉庫 `skins/scene-original/t0-inferno.webp` 的 PNG 格式轉換，512×296，逐像素檢查相同。未重繪、未上採樣，沒有學生照片或資料。
- `flow-prompt.txt`：角色呼吸、微轉頭、眨眼、鼻息與岩漿背景的提示詞。固定鏡頭，保持原角色造型。

## 在 Flow 操作

1. 新建專案，選擇用圖片作為起始畫格的圖生影片功能；功能名稱和模型選項會因帳戶／介面版本不同。
2. 上傳 `t0-inferno.png` 作為起始圖。選橫向 16:9，裁切時保留龍頭與角。
3. 若所選模式支援尾幀，可再用同一張原圖作為尾幀；不支援時只用起始圖。這只是循環的引導，不能保證生成後無縫。
4. 貼上 `flow-prompt.txt`。如果有片長選項，先選約 8 秒；沒有則使用當前模式的預設片長。先生成一個樣片，不要一次生成 18 款。
5. 下載原始 MP4，傳回此對話。無須加入字幕、剪輯或先自行壓縮。

## 樣片通過條件

龍本身有可辨認的呼吸與微轉頭；眼、牙齒、角與鱗片不變形；沒有鏡頭推拉冒充角色動作；頭尾姿勢接近，最後不突然停住或跳回。若角色失真，先減少轉頭，只保留呼吸、眨眼和鼻息，再調整。

收到影片後再檢查首尾動作、裁切、iPad 播放格式與檔案大小，決定能否直接循環或需返工。先選定這一隻的品質，再擴展其他 17 隻。星級、學生資料和正式網站在這一步不變。
