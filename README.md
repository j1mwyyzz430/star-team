# 星星小隊

GitHub Pages 提供靜態前端，Google Apps Script 與原有 Google Sheets 儲存班級資料。

## 2026-10-16 班別、學生管理及多人轉盤

班別可自由命名、新增、改名及刪除；學生可單個或批量加入、勾選批量刪除，亦可在學生編輯視窗單獨刪除。刪除前有確認，可在同頁按「撤銷」；有待派發禮物時須先派發或退款。現有班別及學生編號不變，新編號不會重用，避免禮物和錄音對錯人。最多 30 班，每班 100 人。

轉盤超過 12 人時改用號碼扇區，附可捲動的完整姓名對照；少人時保留縮放頭像。所有出席學生仍有相同機會，同輪不重複及抽中名片功能保留。

**這次需要更新原 Google 部署的 `Code.gs` 和 `Index.html`**，請依 [後台更新指引](google-backend/README.md) 操作。未更新時仍可讀取原資料及加分，新增班別及刪除功能會提示更新。無需重建試算表或重新匯入學生。新格式啟用後不可單獨回退舊後台，詳細相容性及回復限制見指引。

## 覺醒動畫與抽獎操作修正

正式加分及轉盤抽中時，全屏演出須同時達到 Lv.100，並解鎖已裝備角色的「出場動畫」（覺醒第 2 階段）；只有「專屬邊框」時保留名片效果。終極演出仍按第 3 階段啟用，機甲沿用各自的解鎖經驗門檻。全班加分只讓已解鎖的學生參與全屏演出。名片收藏中的明確「試看」仍可預覽完整效果，不會改動分數或解鎖進度。

原問題是全屏播放函式未檢查覺醒階段，普通學生亦會播放基礎演出，再被全屏顯示層放大。現已在播放入口檢查實際解鎖狀態。禮物商店的原有學生選擇及餘額顯示也移到抽獎按鈕上方，抽獎和兌換共用同一選擇。

這兩項修正只涉及 GitHub 前端，無需更新 Google 後台。桌面與 iPad 模擬測試涵蓋等級／覺醒邊界、已解鎖神獸及機甲、試看、跨年級抽獎扣分及窄螢幕排版。

## 記住這部裝置的登入

登入畫面預設勾選「記住這部裝置，下次自動登入」。各裝置登入成功一次後，重新整理、重開網站或新增分頁會沿用有效憑證讀取同一份雲端資料。只保存登入憑證，不保存老師密碼；共用裝置可取消勾選。「設定 → 忘記這部裝置的登入」可清除已保存的憑證，不影響學生資料或本機錄音。

**原附件中的 Google 後台有效期為 12 小時。** 前端可立即記住有效期內的登入；要延長至 90 天，還需按 [Google 後台更新指引](google-backend/README.md) 更新原 Apps Script 部署。GitHub 推送不會自動部署 Google 程式。保留原試算表與部署網址；本次班別升級須一併更新 `Index.html`，不執行首次設定，也不匯入舊備份。

Google 後台新版本只為勾選記住登入的裝置簽發 90 天憑證；未勾選維持 12 小時。90 天到期、清除瀏覽器儲存或後台撤銷憑證後需再次登入。無痕模式或禁止儲存的瀏覽器不能保證記住登入。

## 2026-10-15 登入與跨裝置同步修正

- `config.js` 指向老師提供的原有 `/exec` 後台，優先於各瀏覽器舊有的 `star-backend-url`。新裝置不再需要自行選擇後台；登入畫面的共用網址不能改寫。
- 登入成功後才記住後台網址。瀏覽器禁止 localStorage 時，連線仍可在該分頁內使用；老師密碼不會存入 localStorage。登入憑證可按上述「記住這部裝置」功能保存，並按後台網址分隔。
- 使用 AbortController 與計時器處理逾時，支援沒有 `AbortSignal.timeout` 的 Safari。連線失敗可開啟同一後台的 Google 備用入口，沿用原生 `google.script.run`。
- 更新設定及連線程式的資源版本，避免沿用舊的快取。沒有修改計分規則、資料格式、照片、名片、神獸機甲、動畫或錄音儲存方式。

原本空白的 `config.js` 會令後台網址只存在第一部電腦的 localStorage；其他瀏覽器與裝置無法讀取那份設定。已連線的桌面電腦若仍有未儲存變更，先等待儲存完成再重新整理。**不需要清空資料、建立新試算表或重新匯入舊備份。**

## 發佈與核對

推送至 GitHub Pages 使用的 `main` 分支後，等待 Pages 發佈完成，才在各裝置重新載入網站並用原有老師密碼登入。共用後台與基本記住登入只需發佈前端；班別管理和 90 天有效期另需更新原 Apps Script 部署，仍不需建立新部署、重跑首次設定或更換原試算表。

登入後逐年級核對原有學生、照片、分數、經驗及名片，以及共用禮物、庫存和抽獎權重。任何一部裝置未能連線時，使用登入畫面的 Google 備用入口，先核對連到同一部署。同步衝突時保留當前頁面及未儲存資料，不要用舊備份覆蓋雲端。

個人錄音仍只保存在各瀏覽器的 IndexedDB。換裝置或切換至 Google 入口不會自動取得錄音；本次沒有搬移或刪除錄音，也不需要為了連線問題重新匯入學生備份。

修正前版本為 `cba319e`。如需回復前端，使用 Git revert 撤銷修正提交並重新發佈；這不會回復或改動 Google Sheets 內的分數。

## 本機開發與驗證

在倉庫根目錄執行 `python3 -m http.server 8000 --bind 127.0.0.1`。應用無需套件安裝或建置。

```sh
node --test tests/*.test.cjs
python3 tests/browser_sync.py
python3 -B tests/browser_rewards.py
python3 -B tests/browser_classes.py
```

瀏覽器測試需要 Python Playwright 和 `/usr/bin/chromium`，會自行啟動本機伺服器，所有 Google 請求均由測試攔截，使用人工產生的測試學生與圖片，**不會登入或寫入真實後台**。

已通過 16 項前端連線與登入單元測試及 1 個後台回歸測試檔（Node 共 17 項），以及 Chromium 中桌面／iPad 模擬的跨裝置讀取、重開免重登、加分同步、版本衝突、登入過期、儲存受限、忘記登入與錄音保留檢查。後台測試驗證 90 天與 12 小時有效期、憑證撤銷、照片分塊、儲存衝突及失敗復原。這些並非 iPad Safari 實機驗證。維護環境對 GitHub Pages 與 Google 後台的直接連線被網絡代理以 403 拒絕，因此尚未驗證真實 Google 登入與線上部署結果。

後台網址屬公開設定。老師密碼、學生備份、私人照片及錄音不可加入這個公開倉庫。`google-backend/Code.gs` 只包含不帶實際憑證或學生資料的後台程式；原試算表及 Apps Script 專案繼續保持私人。
